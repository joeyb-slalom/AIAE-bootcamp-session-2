# UI Guidelines: TODO App

## Core UI Guidelines

1. The TODO app UI shall use Material UI components for core interface elements, including forms, buttons, inputs, lists, dialogs, and feedback states.
2. The UI shall maintain a consistent Material Design look and interaction pattern across the application.
3. Custom styling shall extend Material components rather than replace them with inconsistent bespoke controls unless a clear product need requires it.
4. The UI shall provide a responsive design that works effectively across mobile, tablet, and desktop screen sizes.
5. The UI shall use a calm, feel-good color palette that supports a clear, welcoming, and low-stress user experience.
6. The UI shall conform to modern accessibility standards, including sufficient color contrast, keyboard accessibility, visible focus states, and support for assistive technologies.
7. New UI features shall follow the same Material-based component approach to preserve consistency, usability, and accessibility.
