# Coding Guidelines: TODO App

## Core Coding Guidelines

1. The codebase shall prioritize modular, readable code with clear and descriptive naming for files, functions, variables, and components.
2. The codebase shall be organized into well-named folders by tier, separating responsibilities such as frontend UI, backend API, shared utilities, and tests.
3. The codebase shall include useful documentation comments for non-obvious logic, public interfaces, and key architectural decisions to improve maintainability.
4. The codebase shall follow general industry best practices for code style for each programming language used in the application.
